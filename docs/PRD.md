# WorkClock PRD

> 작성: 2026-11-16 · 상태: 초안 (v1.0.0 범위)

## 1. 한 줄 요약

근무 조건을 설정 파일에 적어 두면, macOS 메뉴 막대에 오늘 근무 진행률과 오늘 번 돈을 띄워 주는 작은 앱이다. 계약직이면 계약 진행률까지 보여 준다.

## 2. 배경과 목표

출근해서 "오늘 얼마나 지났지, 오늘 얼마 벌었지, 월급날이 언제지"를 계산기 없이 바로 보고 싶다. 계약직이면 "계약 끝까지 며칠 남았지"도 궁금하다.

**목표**
- 메뉴 막대만 봐도 오늘 근무 진행률과 오늘 번 돈을 알 수 있다.
- 메뉴를 펼치면 남은 날, 출근 일수, 휴가 잔여, 월급일까지 한 번에 본다.
- 계약직과 정규직 모두 쓸 수 있다.
- Homebrew 한 줄로 설치하고, 설치하는 Mac에서 직접 빌드해 Gatekeeper 경고 없이 실행한다.

**비목표 (v1에서 하지 않는 것)**
- 공휴일 자동 반영 (네트워크를 쓰지 않는다. 공휴일은 설정에 직접 적는다)
- 세후 실수령액, 4대 보험, 소득세 계산
- 야근·초과근무 수당, 교대 근무, 요일별 다른 근무 시간
- 설정 화면 GUI (설정은 JSON 파일로만 한다)
- App Store 배포, 다국어 (v1은 한국어 UI)

## 3. 대상 사용자

- **계약직·인턴:** 계약 시작일과 종료일이 정해져 있다. 계약 진행률과 남은 날이 가장 궁금하다.
- **정규직:** 종료일이 없다. 오늘 진행률, 이번 달 번 돈, 월급일, 연차 잔여가 궁금하다.

## 4. 근무 형태

설정의 `employmentType`으로 정한다.

| 값 | 의미 | 계약 관련 표시 |
|---|---|---|
| `"contract"` | 계약직 | 계약 진행률, 남은 날, 출근 일수, "X번 더 하면 끝"을 보여 준다 |
| `"permanent"` | 정규직 | 계약 관련 줄을 모두 숨기고, 입사일이 있으면 근속 일수를 보여 준다 |
| 비어 있음 | 자동 판단 | `contractEnd`가 있으면 계약직, 없으면 정규직 |

계약직인데 `contractStart`나 `contractEnd`가 비어 있으면, 계약 관련 표시만 생략하고 나머지는 그대로 보여 준다.

## 5. 기능

### 5.1 메뉴 막대

SF Symbols 아이콘과 값을 나란히 보여 준다. 1초마다 갱신한다. 숫자는 고정폭 글꼴(monospacedDigit)을 써서 값이 바뀌어도 메뉴 막대가 좌우로 흔들리지 않게 한다.

| 항목 | 표시 조건 | 예시 |
|---|---|---|
| 계약 진행률 | 계약직이고 기간이 있을 때 | `[아이콘] 41%` |
| 오늘 근무 진행률 | 근무일. 소수점 3자리 | `[아이콘] 62.417%` |
| 휴일 | 주말·공휴일·휴가일 | `[휴일 아이콘] 휴일` |
| 오늘 번 금액 | 급여 설정이 있고 「금액 숨기기」가 꺼져 있을 때 | `[아이콘] ₩84,210` |

### 5.2 펼침 메뉴

위에서부터 이 순서로 보여 준다. 조건에 맞지 않는 줄은 숨긴다.

**계약 (계약직만)**
- 계약 진행 41.2% (남은 N일)
- 남은 날 = 평일 N일 + 주말 N일 + 공휴일 N일 + 휴가 N일 (오늘 포함)
- 지금까지 N일 출근 · 이만큼을 X번 더 하면 끝 (남은 N일)

**정규직**
- 올해 N% 지남 (1월 1일 0시 ~ 다음 해 1월 1일 0시 기준)
- 입사 N일째 — `hireDate`가 있을 때
- 다음 연차 발생 M/d(요일) · D-N — `hireDate`가 있을 때 (6.10 규칙)

**휴가**
- 남은 휴가 N시간 (총 N시간 중 N시간 사용) — `leaveHoursTotal`이 0이면 숨긴다

**오늘**
- 오늘 N% 지남 / N% 남음 — 근무일이 아니면 "오늘은 휴일"

**급여 (급여 설정이 있을 때)**
- 오늘 번 돈 ₩N
- 이번 달 번 돈 ₩N
- 통상시급 ₩N (월급 ÷ 월 소정근로시간)
- 다음 월급일 M/d(요일) · D-N — `payday`가 0이면 숨긴다

**설정과 앱**
- 금액 숨기기 (체크 토글, 상태 저장)
- 로그인 시 실행 (체크 토글, SMAppService)
- 설정 파일 열기
- 종료

「금액 숨기기」를 켜면 메뉴 막대의 금액과 펼침 메뉴의 금액 줄을 모두 `₩•••`로 가린다.

### 5.3 CLI

| 옵션 | 동작 |
|---|---|
| `--print` | 메뉴 막대를 만들지 않고, 펼침 메뉴와 같은 내용을 텍스트로 한 번 출력한 뒤 종료 코드 0으로 끝낸다. 설정 파일이 없으면 빈 양식을 만든 뒤 출력한다. 화면이 없는 환경(Homebrew test)에서도 돌아야 한다 |
| `--enable-login` | 로그인 시 실행에 등록하고 결과를 출력한 뒤 종료한다. `.app` 번들 안에서 실행됐을 때만 성공한다 |
| (없음) | 메뉴 막대 앱으로 실행한다 |

## 6. 계산 규칙

모든 날짜와 시각은 Mac의 현재 시간대를 따른다.

### 6.1 날짜 분류

한 날짜는 아래 순서로 처음 맞는 하나에만 속한다.

1. **휴가:** `leaveDates`에 있다
2. **공휴일:** `holidays`에 있다
3. **주말:** 토요일 또는 일요일
4. **평일:** 그 밖의 날. 이 날만 근무일이다

예: 공휴일이 토요일이면 공휴일로 센다. 공휴일에 휴가를 적어 두면 휴가로 센다.

### 6.2 계약 진행률

- 시작: `contractStart` 0시
- 끝: `contractEnd` 다음 날 0시
- 진행률 = (지금 − 시작) ÷ (끝 − 시작), 0~100%로 자른다

### 6.3 남은 날 (오늘 포함)

- 오늘부터 `contractEnd`까지 날짜를 6.1 규칙으로 나눠 센다.
- `leaveDays`(날짜 미정 휴가 일수)는 남은 평일에서 빼고 휴가에 더한다. 남은 평일보다 크면 남은 평일까지만 뺀다.
- 남은 근무일 = 위에서 계산한 남은 평일.

### 6.4 출근 일수와 "X번 더"

- 지금까지 출근 = `contractStart`부터 어제까지의 근무일 수. 오늘이 근무일이고 출근 시각이 지났으면 오늘도 더한다.
- 남은 근무일은 6.3 값에서, 오늘을 이미 출근 일수에 넣었으면 오늘을 뺀다. 같은 날을 두 번 세지 않는다.
- X = 남은 근무일 ÷ 지금까지 출근 일수, 소수점 한 자리. 출근 일수가 0이면 이 줄을 숨긴다.

### 6.5 오늘 근무 진행률

- 근무일만 계산한다. 근무일이 아니면 「휴일」로 보여 준다.
- 진행률 = (지금 − `workStart`) ÷ (`workEnd` − `workStart`), 0~100%로 자른다. 점심시간을 포함한 전체 구간 기준이다.
- `workEnd`가 `workStart`보다 이르면 설정 오류로 보고 이 항목을 숨긴다 (야간 근무는 v1 비목표).

### 6.6 하루 금액

급여 키가 여러 개면 아래 순서로 처음 있는 것 하나만 쓴다.

| 순서 | 키 | 하루 금액 |
|---|---|---|
| 1 | `annualSalary` | 월급 = 연봉 ÷ 12 (`annualIncludesSeverance`가 true면 ÷ 13). 그다음은 2번과 같다 |
| 2 | `monthlyPay` | 이번 달 지급액 ÷ 이번 달 근무일 수 |
| 3 | `dailyPay` | 그대로 |
| 4 | `hourlyPay` | 시급 × 하루 유급 시간 |

- **이번 달 지급액** = 월급 × (이번 달 중 재직 기간의 달력 일수 ÷ 이번 달 달력 일수)
  - 재직 기간: 계약직은 `contractStart`~`contractEnd`, 정규직은 `hireDate`부터. 기간 정보가 없으면 한 달 전체로 본다.
- **이번 달 근무일 수** = 이번 달 재직 기간 안의 평일 수 (6.1 기준, 휴가·공휴일 제외)
- **하루 유급 시간** = (`workEnd` − `workStart`) − `lunchMinutes`

### 6.7 번 돈

- 오늘 번 돈 = 하루 금액 × 오늘 근무 진행률. 근무일이 아니면 0.
- 이번 달 번 돈 = 하루 금액 × 이번 달 1일부터 어제까지의 근무일 수 + 오늘 번 돈
- 모든 금액은 세전이다. 원 단위로 내림하고 천 단위 쉼표를 찍는다.

### 6.8 통상시급

- 월급을 알 때(1·2번): 월급 ÷ `monthlyHours`
- 시급만 알 때(4번): `hourlyPay`
- 일급만 알 때(3번): 일급 ÷ 하루 유급 시간

### 6.9 다음 월급일

1. 이번 달 `payday`일을 후보로 잡는다. 그 달에 그 날짜가 없으면(예: 31일) 그 달 마지막 날로 한다.
2. 후보가 근무일이 아니면, 직전 근무일로 당긴다.
3. 결과가 오늘보다 이전이면, 다음 달로 1~2를 다시 한다.
4. 오늘이 월급일이면 `D-Day`로 보여 준다.

### 6.10 다음 연차 발생일 (정규직)

입사일 기준으로 근로기준법의 기본 규칙만 따른다. 회계연도 기준 부여나 회사별 규칙은 v1 비목표다.

- 입사 1년 미만: 입사일과 같은 날짜가 돌아올 때마다 1일씩 생긴다 (최대 11번). 그 달에 같은 날짜가 없으면 그 달 마지막 날로 한다.
- 입사 1년 이상: 매년 입사 기념일에 생긴다.
- 표시는 다음 발생 날짜와 D-N만 한다. 발생 일수는 v1에서 보여 주지 않는다.

## 7. 설정 파일

### 7.1 위치와 동작

- 경로: `~/.config/workclock/config.json`
- 없으면 아래 빈 양식을 만들고 권한을 600으로 둔다.
- 앱은 10초마다 다시 읽는다. 파일 수정 시각이 그대로면 다시 파싱하지 않는다.
- JSON이 깨졌거나 형식이 틀리면, 마지막으로 읽은 정상 값을 계속 쓰고 메뉴 맨 위에 `⚠︎ 설정 파일 오류: <이유>` 한 줄을 띄운다.
- 「금액 숨기기」와 「로그인 시 실행」 상태는 설정 파일에 쓰지 않는다. 금액 숨기기는 UserDefaults에, 로그인 시 실행은 SMAppService 상태에 둔다. 사용자가 편집하는 파일을 앱이 덮어쓰지 않게 하기 위해서다.

### 7.2 키

| 키 | 형식 | 기본값 | 설명 |
|---|---|---|---|
| `employmentType` | `"contract"` \| `"permanent"` \| `""` | `""` | 비면 `contractEnd` 유무로 판단 |
| `contractStart` | `"YYYY-MM-DD"` | `""` | 계약 시작일 |
| `contractEnd` | `"YYYY-MM-DD"` | `""` | 계약 종료일 (이 날까지 근무) |
| `hireDate` | `"YYYY-MM-DD"` | `""` | 정규직 입사일. 근속 일수와 입사 월 일할에 쓴다 |
| `workStart` | `"HH:mm"` | `"09:00"` | 출근 시각 |
| `workEnd` | `"HH:mm"` | `"18:00"` | 퇴근 시각 |
| `lunchMinutes` | 숫자 | `60` | 시급으로 하루 금액을 낼 때만 뺀다 |
| `annualSalary` | 숫자 | `0` | 연봉 (세전) |
| `annualIncludesSeverance` | true/false | `false` | 연봉에 퇴직금이 들어 있으면 true (÷ 13) |
| `monthlyPay` | 숫자 | `0` | 월급 (세전) |
| `dailyPay` | 숫자 | `0` | 일급 |
| `hourlyPay` | 숫자 | `0` | 시급 |
| `monthlyHours` | 숫자 | `209` | 통상시급 기준 월 소정근로시간 |
| `payday` | 숫자 1~31 | `0` | 월급일. 0이면 표시 안 함 |
| `holidays` | `["YYYY-MM-DD"]` | `[]` | 공휴일·회사 휴무일 |
| `leaveDates` | `["YYYY-MM-DD"]` | `[]` | 날짜가 정해진 휴가 |
| `leaveDays` | 숫자 | `0` | 날짜 미정 휴가 일수 |
| `leaveHoursTotal` | 숫자 | `0` | 시간 단위 휴가 총량. 0이면 휴가 줄을 숨김 |
| `leaveHoursUsed` | 숫자 | `0` | 사용한 시간 |
| `currency` | 문자열 | `"₩"` | 금액 앞에 붙는 기호 |

급여 키는 0이면 없는 것으로 본다.

### 7.3 예시 (README용, 값은 가짜)

```json

  "employmentType": "contract",
  "contractStart": "2026-01-05",
  "contractEnd": "2026-06-30",
```

## 8. 기술 조건

- 소스는 `main.swift` 한 파일. Cocoa와 ServiceManagement만 쓴다. 외부 의존성과 네트워크 호출이 없다.
- Xcode 없이 Command Line Tools의 `swiftc`로 빌드한다.
- 최소 macOS 13.0 (SMAppService 때문).
- 계산 로직은 UI와 분리해 `--print`로 그대로 확인할 수 있게 한다.
- 1초 타이머는 메뉴 막대 표시만 다시 그린다. 펼침 메뉴는 열릴 때 계산한다.

### 8.1 build.sh

1. `swiftc -O main.swift -o WorkClock`
2. `WorkClock.app/Contents/{MacOS,Info.plist}` 번들 생성. Info.plist는 직접 쓴다 (`LSUIElement=true`, `LSMinimumSystemVersion=13.0`, `CFBundleIdentifier`, `CFBundleShortVersionString`)
3. `codesign --force --sign -` ad-hoc 서명
4. `~/Applications/WorkClock.app`에 설치 (기존 앱이 실행 중이면 종료 후 교체)

## 9. 배포

### 9.1 저장소

| 저장소 | 공개 범위 | 내용 |
|---|---|---|
| `msk226/work-clock` | 개발 중 비공개 → v1.0.0 출시 때 공개 | 앱 소스, build.sh, README, LICENSE, docs |
| `msk226/homebrew-tap` | 공개 (출시 때 생성) | `Formula/workclock.rb` |

- formula는 설치하는 Mac에서 소스 tarball을 내려받는다. 소스 저장소가 비공개면 `brew install`이 실패하므로, 태그를 달기 전에 공개로 바꾼다.
- 실제 급여가 든 `config.json`은 저장소에 넣지 않는다. `.gitignore`에 `config.json`을 둔다.

### 9.2 Formula

- `url`: v1.0.0 태그 tarball, `sha256`: tarball 해시
- `depends_on macos: :ventura`
- `install`: `swiftc -O`로 빌드 → `prefix/"WorkClock.app"` 번들 생성 → ad-hoc 서명
- `bin/"workclock"`: 심볼릭 링크가 아니라 `.app` 안의 실행 파일을 부르는 짧은 셸 스크립트 (`exec ".../WorkClock.app/Contents/MacOS/WorkClock" "$@"`). 심볼릭 링크로 실행하면 앱 번들을 못 찾아 로그인 시 실행 등록이 실패할 수 있다.
- `caveats`
  - `~/Applications`에 링크하는 방법: `ln -sf "$(brew --prefix workclock)/WorkClock.app" ~/Applications/WorkClock.app`. 복사하면 `brew upgrade`가 복사본을 바꾸지 않는다.
  - 로그인 시 실행: 메뉴에서 켜거나 `workclock --enable-login`
  - 업그레이드 뒤 로그인 시 실행이 꺼져 있으면 다시 켠다 (빌드할 때마다 ad-hoc 서명이 바뀐다)
- `test`: `workclock --print`가 0으로 끝나는지

### 9.3 확인

- `brew install --build-from-source ./Formula/workclock.rb`
- `brew audit --strict --new workclock`
- `brew test workclock`
